# Student Guide

Offline planner for students. Package: `com.audrey.student.guide`.

## Features

- Home dashboard with GPA, study streak, today’s classes, due work, and exam countdown
- Tasks, weekly timetable, and exams
- Subjects, weighted scores, and 4.0 GPA
- Notes, flashcards, Pomodoro timer
- Built-in study tips
- Light/dark theme, local backup export/import

All data stays on the device.

## Run

```bash
flutter pub get
flutter run
```
